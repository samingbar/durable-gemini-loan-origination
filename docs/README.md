# Docs

Short, focused guides for working with Temporal in this repo.

**What to read**
- `temporal-primitives.md` explains the core concepts used in the workflows.
- `temporal-patterns.md` dives into advanced patterns and tradeoffs.
- `testing.md` covers the test strategy and fixtures.
- `write-new-workflow.md` is the step-by-step guide for adding a new workflow.

**Suggested order**
- Start with `temporal-primitives.md`, then `write-new-workflow.md`, then `testing.md`, then `temporal-patterns.md`.
